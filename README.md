# 看盤視窗

富邦 Neo API 桌面看盤與下單程式（PySide6），不使用 Web。

完整的安裝、操作與故障排除說明請見 [繁體中文使用手冊](使用手冊.md)。

## 畫面配置

- 左側：看盤視窗／漲停監控／ETF 折溢價導覽頁籤
- 左上：精簡庫存持股與即時漲跌
- 右上：台指期／加權指數頁籤，即時行情與走勢
- 左下：「快速下單／預掛查詢」頁籤；預掛查詢可逐筆勾選取消
- 右下：個股歷史日 K 棒

看盤頁四個區塊使用可拖曳分割線，可自由調整上下與左右大小。下單市場、買賣方向及價格類型皆使用按鈕選擇；買進為紅色、賣出為綠色，不需再勾選確認核取方塊，但送單前仍保留最終確認對話框。

日 K 採自繪圖表：紅綠實體沒有任何外框，只有上下影線使用白色。股票下單可選「一般／預掛」；「預掛」是程式自己的排程佇列，會把 ROD 限價單保存至 `pending_orders.json`，到下一個工作日 08:31 且成功登入後才送至富邦。程式在預定時間必須保持開啟並登入；若尚未登入，會在下次登入時補送。台指期不提供預掛。

本機預掛在執行前尚未進入券商委託系統，不會出現在富邦委託查詢；成功送出後才會取得委託書號。若券商回覆尚未開放收單，程式會自動順延至下一個工作日 08:31；其他錯誤會保留為待確認狀態，不會無限重送。

加入預掛後，程式會自動切換到「預掛查詢」頁籤。表格會顯示方向、商品、委託價、數量、預計送出時間與狀態；勾選尚未送出的項目後按「取消勾選掛單」即可移除。處於「送出中」的項目不可取消，以避免委託狀態不明。

## 漲停監控

登入後每 30 秒呼叫富邦 `query_symbol_snapshot` 掃描標的。使用者可直接調整「距漲停 tick 數」與「最低成交量（張）」；候選標的會再以 Intraday Quote 的 `closePrice` 與 `total.tradeVolume` 複核，避免使用試撮價格。

股票分類可選全部一般股、上市、上櫃、ETF／ETN、可轉債，以及台灣50、台灣中型100、台灣50＋中型100、小型股300。台灣50與中型100取自元大0050／0051官方每日PCF；小型股300依證交所編製規則，以官方發行股數和富邦參考價計算上市市值第151～450名。分類每日更新一次並快取於 `stock_groups.json`。

每筆符合條件的標的都有「市價買進」按鈕，也可先選取表格中的股票，再按上方「市價追選取標的」。追單數量以「張」輸入，送至富邦 SDK 時會依商品交易單位換算成股數（一般股票通常每張 1,000 股）。按下後仍會顯示商品、張數、換算股數與市價風險的最終確認，確認後送出股票現股市價 ROD 委託。

監控頁最下方的「程式執行訊息」會保留最近一次掃描或追單結果；掃描例外、SDK 例外與券商拒單原因都會顯示在這裡，關閉彈窗後仍可查看。

## 啟動

1. 安裝 Python 3.11～3.13。
2. 第一次使用先雙擊 `install.bat` 安裝富邦 Neo SDK 與 PySide6。
3. 雙擊 `start.bat` 啟動，畫面上只需輸入富邦帳號與密碼。

正式環境仍必須依富邦規定使用 PFX 憑證；程式會記住既有憑證路徑，第一次登入時以彈窗取得憑證密碼，並使用 Windows DPAPI 綁定目前 Windows 使用者加密保存。若憑證密碼錯誤，程式會自動清除並於下次登入重新詢問。

登入後，程式先透過 HTTP API 載入庫存、行情、指數參考價與日 K，再由 WebSocket 持續更新。實際送單前會再次顯示完整委託內容並要求確認。

## 安全提醒

`settings.json`、`pending_orders.json`、`stock_groups.json`、`log/` 及 PFX/P12 憑證均被排除在版本控制之外。請勿把帳號、密碼或憑證提交到公開儲存庫。使用真實下單功能前，請先以小額委託確認參數與風控設定。
